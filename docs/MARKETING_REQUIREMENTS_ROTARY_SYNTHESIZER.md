# Marketing Requirements Document (MRD): Auncient Synthesizer & Rotary Sequencer Subsystem

## 1. Executive Summary
The Auncient Synthesizer & Rotary Sequencer Subsystem positions the Dysnomia VM at the convergence of electromechanical tangible user interfaces, harmonic sound synthesis, and formal cryptographic ledger verification. By repurposing Strowger rotary diallers and uniselector stepping switches as tactile physical sequence controllers for 5-instrument overdrive synthesis (Sub-Bass, FM, Lead, Kick, Snare), the system delivers a zero-latency, tactile music production and cryptographic gating terminal.

## 4. Key Feature Requirements

### 4.1 Physical Rotary Dialler Interface
* **Pulse-Train Generation**: Direct translation of mechanical 10 PPS break-make dial contacts into gate signals.
* **Multi-Decade Stepping**: Uniselector rotary positions [0..9] select active instrument tracks and octave transpositions.
* **Recoil Dynamics**: Spring governor return speed modulates filter cutoff sweeps and envelope release slopes.

### 4.2 5-Instrument Overdrive Synthesis Engine
* **Sub-Bass Generator**: Sine/triangle hybrid with sub-harmonic octaver locked to motzkin modular field limits.
* **FM Modulator**: Dual-operator carrier-modulator pairs with variable index gating.
* **Harmonic Lead**: Overdriven pulse-width waves shaped by 4-point Newton-Gregory forward difference interpolation.
* **Percussive Voices**: Mechanical kick and snare drums triggered via Strowger uniselector detent contacts.

### 4.3 Telephony Box Testing & Verification
* **Blue Box Mode**: In-band 2600 Hz SF trunk line seizure and multi-frequency operator routing.
* **Red Box Mode**: Dual-frequency (1700 Hz + 2200 Hz) ACTS coin deposit pulse telemetry in the universal accumulator.
* **Black Box Mode**: Loop-current interlock holding supervisory current at 0 mA for zero-leakage isolation.
