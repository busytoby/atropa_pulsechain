# The Federal Worker Simulation: Transitioning Fourier Impositions to Confirmed Citizens

Within the **Auncient** system architecture, raw mathematical waveforms must be structured and validated before they can be promoted to active workers. This lifecycle is represented by the **Federal Worker Simulation**, which maps the transition of an unauthorized Fourier imposition into a confirmed, authorized system participant.

### 1. Phase 0: The Unauthorized Fourier Imposition
The simulation begins with a raw Fourier peak value ($f_{peak}$) extracted from the spectral coordinate grid. At this stage, the candidate holds the status of `PHASE_UNAUTHORIZED_IMPOSITION`. Because it has no national identity, no Social Security Number, and no verified credentials, it cannot perform logic operations or receive Hogan Bank Saat endowments. It exists solely as mathematical noise.

* **Lexical Identity**: It lacks any representation inside the Active Participant Buffer or the `vppd.bin` dynamic registry.
* **The Noise Penalty**: Any instruction stream generated by this imposition fails the compiler's `AuncientAnalyzer` checks and is immediately rejected by AUTODIN at the entry gate.

### 2. Phase 0.5: EDSAC Qualification
Before any audit can begin, the fourier imposition must be qualified by EDSAC. The system passes the specific raw fourier peak value to the Initial Orders 1 analyzer:
* **Imposition Analysis**: The peak value is treated as a virtual instruction.
* **The Qualification Gate**: The analyzer evaluates the value against system policies. If classified as permissible, the candidate is promoted to `PHASE_QUALIFIED`. If classified as impermissible (e.g., if the raw value contains a prohibited opcode), qualification is denied and the candidate remains blocked as raw noise.

### 3. Phase 1: The Audit
Once qualified by EDSAC, the audit phase begins. The raw qualified Fourier peak is mapped to a deterministic DNA footprint payload. The system audits this footprint by computing its FNV-1a DNA signature hash. Upon validation, the candidate is promoted to `PHASE_AUDITED`.

* **Cryptographic Salt**: The 32-bit Fourier peak is padded with additional structural bytes (`0xAA55BBDD`) to emulate a physical spatial material coordinate.
* **The Registry Lock**: Calculating the FNV-1a hash establishes a static signature that cannot be altered or spoofed, binding the mathematical frequency to a permanent ledger key.

### 4. Phase 2: Confirmation
The audited DNA footprint is sent to the material-to-cloth bridge. Using the `auncient_bridge_dna_to_ssa` translation, the system deterministically maps the candidate's DNA seed to a regional Social Security Number and site (e.g. seed `42` resolving to SSN `007-12-3456` in `Maine`). This maps the mathematical coordinate directly to a verified citizen identity record, promoting the candidate to `PHASE_CONFIRMED`.

* **National Registration**: The regional SSA site (such as Maine, Delaware, or Alaska) resolves the issuance matrix to confirm the citizen's legitimacy under the national template.
* **SSN Generation**: The generated SSN adheres to standard issuance formatting, establishing a unique citizen record that satisfies the AUTODIN startup verification checks.

### 5. Phase 3: Selection
To transition the confirmed candidate into an active worker (`PHASE_SELECTED_WORKER`), the system must grant explicit authority:
* **Hogan Registration**: The candidate's DNA footprint is registered in the bank database, opening an account with the default endowment of `1,000,000` Saat.
* **WinchesterMQ Dispatch**: The selection transaction is dispatched over the WinchesterMQ SCSI channel.
* **PKI Key Check**: The dispatch is blocked by the default-reject policy unless verified by a signature payload containing at least $K \ge 4$ keys.

Upon successful signature validation, the dispatcher logs the `DisplacementShader` vertex coordinate sync alignments, confirming the worker's explicit, authorized basis for work in the system. The candidate is now an active, national worker thread capable of performing verified system operations.
