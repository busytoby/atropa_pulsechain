## Game Mechanics & Historical Gameplay Architecture: Keys Of Ong (ARCADIA)

`Keys Of Ong` represents an on-chain cryptographic prediction game designed to empirically measure and test guessing difficulty across our constant-entropy random number generator (RNG) infrastructure:

```
[Keys Of Ong Constant-Entropy RNG Game Pipeline]
+-----------------------------------------------------------------------------------+
|                                Keys Of Ong (ARCADIA)                              |
+-----------------------------------------------------------------------------------+
|  1. Underlying RNG Engine: Deterministic modpow modular exponentiation sequence   |
|  2. Prediction Submission: Function 0xbce3821f(uint256 predicted_rng_state)       |
|  3. libAtropaMath Validation: Verifies predicted state against active RNG round   |
|  4. Reward Emission: Exactly 1.0 ARCADIA token minted per verified prediction     |
|  5. Empirical Entropy Audit: Tracks computational difficulty of on-chain guessing |
+-----------------------------------------------------------------------------------+
```

1. **RNG Number Prediction Mechanics**:
   * The underlying Random Number Generator operates on a clean, deterministic modular exponentiation (`modpow`) sequence over fixed system primes.
   * Although mathematically deterministic, predicting the next sequential state requires calculating modular trajectories ahead of state progression.
2. **Gameplay Execution & Reward Minting**:
   * Players submit their predicted RNG number to function selector `0xbce3821f(uint256 key_attempt)`.
   * If the submitted prediction matches the active state derived by [`dynamic_0xb680f0cc810317933f234f67eb6a9e923407f05d`](https://scan.pulsechain.com/address/0xB680F0cc810317933F234f67EB6A9E923407f05D) (`libAtropaMath v1.1`), the contract awards and mints `1.0` ARCADIA (`Keys Of Ong`) token directly to the player.
3. **Transaction Execution Trace Verification**:
   * On-chain transaction records confirm that player calls pass a candidate `uint256` prediction parameter to selector `0xbce3821f`.
   * The contract invokes the linked [`dynamic_0xb680f0cc810317933f234f67eb6a9e923407f05d`](https://scan.pulsechain.com/address/0xB680F0cc810317933F234f67EB6A9E923407f05D) random calculation routine during transaction execution.
   * Whenever the generated RNG number matches the submitted prediction, the execution path triggers a `Transfer(0x0, player, 1000000000000000000)` event, minting exactly `1.0` ARCADIA to the winning account.
4. **Entropy & Difficulty Testing Framework**:
   * The game serves as an empirical test harness for the Dysnomia VM, evaluating whether constant-entropy modular operations remain resilient against rapid brute-force or state-prediction attacks in adversarial network environments.
5. **Symbolic Lore (Ong & Arcadia)**:
   * **Ong's Hat / Ong lore**: Draws thematic inspiration from the early interdimensional gateway mythos of Ong's Hat, where discovering the correct harmonic key opens the gateway.
