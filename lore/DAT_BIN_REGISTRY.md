## 70. ZMM System State Schema (`zmm_system_state.dat.bin`)
To represent the simulated hardware architecture and internal runtime memory under **Auncient** constraints (Rule 13), a unified layout is defined below:

| Offset Range | Size (Bytes) | Component Name | Description |
|---|---|---|---|
| `0x0000 - 0x00FF` | 256 | System Header | Magic bytes `ZMM_DAT_BIN`, version, metadata, checksum |
| `0x0100 - 0x01FF` | 256 | VM CPU & SCSI registers | Mappings for `Base`, `Channel`, `Chin`, `Dynamo`, `Signal`, `Secret`, `Element`, `Pole`, `MotzkinPrime`, `PC`, and `SP` |
| `0x0200 - 0x101FF` | 65,536 | System RAM | 64KB simulated address space |
| `0x10200 - 0x201FF` | 65,536 | VRAM Frame Buffer | Raster state for the 256x256 8-bit display |
| `0x20200 - 0x203FF` | 512 | Graphics Matrices | Active transforms, locator coordinates, and viewport clipping limits |
| `0x20400 - EOF` | Variable | Scene Graph ledger | Serialization of the active `MallgrenSceneNode` parent-child nodes |
