# CBT Tape Personalities under VAESEN Classification

In the **Auncient** telemetry logs of the XplOS mainframe scheduler, all active entities and operator user accounts residing on the CBT Tape archives are classified as VAESEN. This includes system-defined profiles and automated agents:

1. **MVSUSER**: Mainframe admin session coordinator.
2. **JES2**: Spool and queue scheduler daemon.
3. **VTAM**: Telecommunications line driver interface.

Every session and transaction initiated by these accounts is audited under SMF Type 80 records.
