# RFC 812 (NICNAME / WHOIS Protocol): VSEn & WinchesterMQ Implementation

## 1. Protocol Specification Overview
**RFC 812** (*NICNAME / WHOIS*, March 1982, K. Harrenstien, V. White, SRI-NIC) establishes the standard protocol over TCP port 43 for querying the Network Information Center (NIC) administrative and registration database.

Key protocol semantics:
- ASCII command-line interface over TCP port 43.
- Sub-query keywords for handles (`$handle`), networks (`!net`), autonomous systems, and administrative contacts.

---

## 2. VSEn Architecture & Registry Resolution
Within the VSEn and Dysnomia VM environment:
1. **Port 43 CCW Spool Driver**:
   - Inbound WHOIS queries to port 43 dispatch through VSEn channel buffers.
   - Lookups evaluate `dynamic_<address>` contract addresses and RFC 1117 ASNs across the 8-way compute fabric.
2. **Deterministic NIC Handle Resolution**:
   - Resolves NIC handles (e.g. `[JBP]`, `[SRI-NIC]`, `[HWB]`) and citizen participant public key hashes directly from 2-3 Tree AST Merkle roots.
3. **Lossless Commutation Integration**:
   - Administrative ownership records tie to verified smart contract registrations (`Delegate` / `CHO` contract structures).

## 3. Netfind Autonomous Discovery Flow
- Netfind utilizes WHOIS gateways to resolve unknown domain identifiers to authoritative network blocks and gateway ASNs before initiating local WinchesterMQ SCSI sweeps.
