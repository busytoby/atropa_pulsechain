# TSFI2 NATO-Compliant STANAG 4607 GMTI Encoder Guide

## 1. Overview
The STANAG 4607 Encoder provides a NATO standardized interface for exporting target location coordinates generated by the TSFI2 Listening Ears direction-finding receiver array. By compiling coordinate tracks into packed binary segments, the system ensures real-time target interoperability across coalition Command and Control (C2) systems.

## 2. Technical Architecture
The encoder compiles localization updates dynamically into standard-compliant Ground Moving Target Indicator (GMTI) packets:

*   **Coordinate Scaling**: Target coordinates are mapped using standard scaling equations:
    *   $\text{Latitude (Scaled)} = \text{Latitude (Degrees)} \times 10^7$
    *   $\text{Longitude (Scaled)} = \text{Longitude (Degrees)} \times 10^7$
    *   $\text{Elevation (Scaled)} = \text{Elevation (Meters)} \times 10^3$ (packed in millimeters)
*   **Media Layout**: The output stream is saved to disk as a binary file using the `.dat.bin` extension, adhering to the database storage layout guidelines.

## 3. Data Structures
```c
typedef struct __attribute__((packed)) {
    char version[4];           // Format Version (e.g., "G2.0")
    uint32_t packet_size;      // Total Packet Size (Bytes)
    char nationality[2];       // Country Code (e.g., "US")
    char classification;       // Security Code ('U' = Unclassified)
    char mission_id[12];       // Mission Identification Label
    uint8_t datetime[9];       // Binary Time Tag
} STANAG4607Header;

typedef struct __attribute__((packed)) {
    uint8_t segment_type;      // Segment type (0x01 for Target Track)
    uint32_t segment_size;     // Size of the segment block
} STANAG4607SegmentHeader;

typedef struct __attribute__((packed)) {
    uint32_t target_id;        // Track Identity Key
    int32_t latitude;          // Lat * 1e7
    int32_t longitude;         // Lon * 1e7
    int32_t elevation;         // Elev * 1e3
} STANAG4607Target;
```

## 4. Compilation and Validation
To build the verification utility and run target assertions:
```bash
make bin/test_stanag4607_encoder
./bin/test_stanag4607_encoder
```
The program will write the target record coordinates to `bin/stanag_track.dat.bin`, read the data back, and assert coordinate restoration integrity.
